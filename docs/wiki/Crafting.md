# 合成配方

插件会自动注册 16 色配方（与染料/地毯颜色对应）。

## 1. 牌堆 Deck of Cards

```text
P P P
R B C
P P P
```

- `P` = 纸
- `R` / `B` = 同色染料
- `C` = 青色染料

## 2. 牌桌 Card Table

```text
#
c
@
```

- `#` = 物品展示框
- `c` = 同色地毯
- `@` = 任意木板（`#planks`）

## 3. Joker 袋 Joker Grab Bag

产出数量：4

```text
  P
R B C
  P
```

- `P` = 纸
- `R` / `B` = 同色染料
- `C` = 青色染料
