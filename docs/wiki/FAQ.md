# 常见问题（FAQ）

## 1. 需要资源包吗？

不强制。

- 不装资源包：玩法完全可用。
- 装资源包：显示完整卡牌与牌桌模型。

## 2. 为什么空手点牌位没反应？

常见原因：

- 牌位已锁定
- 副手物品不兼容（副手必须为空、卡牌或牌堆）

## 3. 为什么看不到自定义模型？

通常是资源包未安装或未生效。

## 4. 有权限节点或管理命令吗？

当前版本没有提供权限节点和管理命令，核心通过合成与交互完成。

## 5. Joker 袋为什么不是右键立即出牌？

当前设计与原行为一致，走“食用动作触发”链路：

- 触发后取消默认消耗结果
- 扣除 1 个 Joker 袋
- 生成红/蓝 Joker 各 1 张
